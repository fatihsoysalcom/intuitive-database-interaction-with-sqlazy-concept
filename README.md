# Intuitive Database Interaction with SQLazy Concept

This Python script demonstrates the core concept of SQLazy: simplifying database interactions. It shows how to create a database, populate it, and query it using more intuitive functions, abstracting away complex raw SQL.

## Language

`python`

## How to Run

1. Save the code as `sqlazy_concept.py`.
2. Run from your terminal: `python lazy_concept.py`
